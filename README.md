## Como executar
1. Instale as dependências: `pip install fastapi uvicorn pyjwt pytest httpx`
2. Inicie o servidor: `uvicorn main:app --reload`
3. Acesse a documentação Swagger em: `http://localhost:8000/docs`

## Como rodar os testes
Execute o comando `pytest` no terminal para rodar a suíte automatizada.
